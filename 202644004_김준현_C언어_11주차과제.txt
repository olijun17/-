01 . 다음 중 문자열에 대한 설명으로 옳지 않은 것은?
	1. 문자열은 char형 배열로 표현할 수 없다.
	2. 문자열의 마지막에는 널 문자("역슬래시 0")가 추가된다.
	3. 문자 'A'와 문자열 "A"는 동일하게 1바이트의 메모리를 사용한다.
	4. 널 문자는 문자열의 끝을 나타내는 역할을 한다.

02. 다음 코드에 대한 설명으로 옳은 것은?

	char *str = "Hello";
	
	1. 문자열 "Hello"의 내용을 자유롭게 수정할 수 있다.
	2. str은 문자열의 시작 주소를 저장하는 포인터 변수이다.
	3. str은 반드시 6바이트의 메모리 공간을 할당받는다.
	4. str은 다른 문자열을 가리키도록 변경 할 수 없다.

03. 다음 중 구조체와 공용체의 차이에 대한 설명으로 옳은 것은?
	1. 구조체는 하나의 메모리 공간을 모든 멤버가 공유한다.
	2. 공용체는 모든 멤버의 값을 동시에 독립적으로 저장한다.
	3. 구조체는 서로 다른 자료형의 데이터를 하나로 묶을 수 있다.
	4. 공용체는 struct 키워드를 사용하여 선언한다.

04. 다음 코드의 실행 결과에 대한 설명으로 옳은 것은?

	union Data {
		int a;
		float b;
	};

	int main() {
		union Data d;
		d.a = 10;
		d.b = 3.14;

		printf("%f", d.b);
	}

	1. 10
	2. 3.14
	3. 0
	4. 두 멤버가 메모리를 공유하므로 실행 결과를 예측 할 수 없다.

05. 다음 중 C 언어의 열거형에 대한 설명으로 옳은 것은?
	1. 문자열을 저장하기 위해 사용하는 자료형이다.
	2. union 키워드는 사용하여 정의한다.
	3. 열거형은 관련된 상수들의 집합을 정의하는 데 사용한다.
	4. 열겨형의 멤버는 반드시 문자열이여야한다.
